# Regla 02 — Internacionalización

No hay librería de i18n. Es un objeto tipado en `src/i18n/translations.ts` (~531 líneas):

```ts
export const LANGS = ["en", "es"] as const;
export type Lang = (typeof LANGS)[number];
export const translations: Record<Lang, Translations> = { en: {...}, es: {...} };
```

## Regla no negociable

**Todo texto se añade/edita en `en` y en `es`, en el mismo turno.** El tipo
`Record<Lang, Translations>` obliga a que ambas ramas tengan la misma forma: si dejas una
a medias, el build revienta o —peor— pasa con un texto en el idioma equivocado.

Orden de trabajo al añadir una clave nueva:

1. Añade/extiende el **tipo** de la sección (`HeroTexts`, `ExperienceItem`…).
2. Añade la clave al objeto **`en`**.
3. Añade la clave al objeto **`es`**.
4. Usa la prop `t` en el componente.

## Cómo editar este fichero sin quemar contexto

Es largo. **No lo leas entero.** Localiza primero:

```bash
grep -n "experience:" src/i18n/translations.ts     # dónde empieza cada sección
grep -n "^\s*es:" src/i18n/translations.ts         # dónde arranca la rama ES
```

Luego lee solo el rango con `Read` + `offset`/`limit`. Para verificar simetría entre
idiomas, compara claves con un `grep` en vez de leer los dos bloques enteros.

## Marcado dentro de traducciones

Se admite **un único** pseudo-tag: `<highlight>…</highlight>`.

- `Hero.astro` lo sustituye por `<span class="text-primary">`.
- `About.astro` lo sustituye por `<strong class="text-primary">`.
- Se renderiza con `set:html`. **No es HTML libre**: no metas `<a>`, `<br>` ni nada más ahí.
  Si necesitas un enlace dentro de un párrafo traducido, parte el texto en varias claves.

## Rutas de documentos

En el diccionario van **sin** la base: `document: "/documents/foo.pdf"`.
El componente antepone `import.meta.env.BASE_URL`. Si escribes la ruta con la base dentro
del diccionario acabas con `/portfolio-alex/portfolio-alex/documents/...` → 404.

## Cambio de idioma

`LanguageToggle.svelte` (isla `client:load`) navega entre `/portfolio-alex/` y
`/portfolio-alex/es/`. Antes de navegar guarda `window.scrollY` en
`sessionStorage["portfolio-scroll-y"]`; al montar en destino lo restaura y borra la clave.
**Todos los accesos a `sessionStorage` van en `try/catch`** (modo privado / storage bloqueado).

Si añades una ruta nueva bilingüe (p. ej. `/projects/` y `/es/projects/`), el toggle
tendrá que mapear la ruta actual en vez de alternar entre dos fijas: refactoriza la función
de navegación, no metas más `if`s encadenados.

## Calidad de las traducciones

- El ES es el idioma nativo de Alex: natural, sin calcos del inglés.
- El EN debe sonar a perfil técnico internacional, no a traducción literal del ES.
  "Técnico informático" → *IT Technician* / *Systems Technician*, no *Computer Technician*.
- Nombres propios de empresas, titulaciones oficiales y certificaciones **no se traducen**.
  Sí se puede añadir una glosa en EN: `Grado Superior (Higher Vocational Degree)`.
- Mantén la longitud parecida entre idiomas: el diseño es a base de tarjetas y un texto ES
  un 30% más largo rompe el grid.
